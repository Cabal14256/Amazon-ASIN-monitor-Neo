# 仪表盘 API

关联 #113。Neo 提供 `GET /api/v1/dashboard`，返回完整 Legacy 仪表盘结构。需要登录，首页查询不要求 `monitor:read` 或 `analytics:read`；其他业务接口继续执行各自权限校验。Legacy 路由保留，前端 Home/AppShell 和监控调度另行迁移。

## 返回语义

- 响应为 `{ success: true, data, errorCode: 0 }`，包括总览、US/UK/DE/FR/IT/ES 和 EU_TOTAL、国家分布、最近更新的 10 个异常组与 10 个异常 ASIN、最近 20 条活动。JP 等其他国家参与全局和分布统计，不计入欧洲五国。
- 有效异常包含自动异常、人工异常和父组人工异常继承；ASIN 的人工排除只抵消父组继承。父组自身自动异常不会自动把全部子 ASIN 标为异常。列表中的 `variant_status` 原样保留存储值。
- 今日起点使用 UTC+8 零点。只统计 `check_type = ASIN` 且 ASIN 仍存在的历史；沿用 Legacy 没有结束边界的语义，未来时间记录也会参与。最近活动不排除孤立历史。
- 最近活动保留所有历史字段、生成的小时/日/月时间、NULL/0/1 和原有七个驼峰别名。关联的组名、ASIN 名称和 ASIN 编码取当前记录，关联缺失时为 NULL；历史快照名称不会回填当前名称，`asin_code` 等独立快照字段仍保留。
- 所有数据库墙上时间按 UTC+8 转为 ISO 时间。`check_result` 返回完整 JSON 字符串；PostgreSQL JSONB 会改变 Legacy TEXT 的空白和对象键顺序，但不删减 JSON 值。不添加监控历史接口独有的 `checkResult`/`asinType` 别名。
- 国家分布的 `total` 保留数字类型，`broken` 保留 MySQL SUM 的十进制字符串类型；国家总览保留 Legacy 对国家标签的严格相等查找，不把单独的 `us ` 隐式改成 `US`。

两个旧查询没有指定的选择规则在 Neo 中固定下来：相同更新时间的告警按 ID 升序，相同检查时间的活动按 ID 降序；等值国家标签混用时，分组代表标签取原始标签按二进制排序的最小值。例如同一分组同时包含 `us ` 和 `US` 时，Neo 固定使用 `US`，而 Legacy 可能返回 `us `，使随后的严格 JS 查找漏掉 US 汇总。这是明确的兼容差异，集成测试分别断言两者实际结果，不通过修改旧响应掩盖差异。单独存在的小写/尾空格标签保持原样；上线前仍须检查真实国家标签和既有迁移对账报告，不自动改写源数据。

## 一致性和缓存

需要 `AUTH_DATA_AUTHORITY=postgresql`。同一只读事务先取得共享管理锁，检查当前账户状态、密码策略和会话，再使用缓存或查询数据。缓存命中不能绕过已提交的账户停用、密码过期和会话撤销。

一次 SQL 语句取得所有业务汇总和列表，使用同一数据快照。进程缓存固定 30 秒，不跨 UTC+8 日期或时钟回拨复用；事务提交成功后才发布缓存，较早开始但较晚完成的查询不能覆盖更新的一代缓存。响应使用 `Cache-Control: no-store`。不同 API 进程独立缓存，因此业务变化最多延迟一个缓存周期显示。

## 资源限制和运维

每个 API 进程最多同时承接两个仪表盘请求，在鉴权前占用名额，直到数据库工作和响应送达结束才释放；过载返回 429。数据库层另有限制池等待的四个事务名额、10 秒总期限、1.5 秒初始鉴权/锁等待和 5 秒业务 SQL 期限。超时返回固定 504，不返回部分统计。

数据库在构造大 JSON 前计算保守容量上界，应用再检查完整响应，预算为 32 MiB；超过预算返回 413，不截断活动或 JSON。兼容 MySQL 唯一 ID 语义，拒绝 PostgreSQL 中大小写/尾空格等值的重复当前组或 ASIN ID，防止联接使计数翻倍。其他失败返回固定 500；日志只记录原因标识，不输出 SQL、连接详情或活动正文。

本次没有新增数据库迁移或生产流量切换。需要现有基线和导入比较排序规则升级；回滚应用提交即可撤销 Neo 入口，旧 Express 入口继续可用。

## 验证方法

单元测试执行实际 Legacy 控制器映射，HTTP 测试覆盖当前授权、缓存期限、并发和错误结果。Integration 工作流在独立 MySQL 数据库与 PostgreSQL 私有 schema 中执行实际旧控制器和 Neo HTTP，逐字段比较完整结果；仅对 `check_result` 的完整 JSON 值消除 TEXT/JSONB 排版差异。还覆盖真实锁等待、提交后撤权、资源上界及失败后的连接/缓存恢复。隔离数据库验证不能代替生产数据对拍、规模测试和阶段切流门槛。
