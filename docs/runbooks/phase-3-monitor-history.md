# P3：Neo 主营监控历史

关联 Issue #141。Neo `/monitor-history` 通过受 `monitor:read` 保护的 `GET /api/v1/monitor-history` 与 `GET /api/v1/monitor-history/:id` 提供只读列表及详情。Legacy 页面与生产入口继续保留。

## 行为与边界

- 服务器执行变体组 ID/名称、ASIN ID/名称/类型、多值 ASIN、国家、检查类型、异常状态和时间筛选。ASIN 以逗号或空白分隔；表单时间按上海墙钟发送，不经过浏览器本地时区或 UTC 转换。
- Legacy 目录的 `/monitor-history?type=group|asin&id=...` 链接会将组或 ASIN ID 写入首屏表单与首个查询；翻页保留该范围。同一路由切换到另一个链接时重新载入对应范围。筛选提交先检查共享请求 URL 上限，过长时提示缩减条件。
- 默认每页 10 条，可选 20/50。`total: null` 明确显示“总量未统计”，满页时允许查看下一页；不把 `null` 当作 0。切换筛选、页码或每页数量时收起旧详情。
- 宽屏表格与窄屏卡片展示状态、检查时间、名称快照、类型、国家和通知状态；详情只展示明确的快照字段和最多 4000 字符的检查结果预览，不将未知 JSON 展开到列表。
- 监控历史读取最多 64 MiB，与数据库查询的保守响应预算一致；共享 HTTP 仍默认 8 MiB，仅此端点显式提高上限。超量数据先由 API 以 413 拒绝，客户端也保留字节与读取块数限制。
- 400/404/413/429/503、客户端响应上限、空结果和刷新失败均显示对应处理提示；旧数据刷新失败时明确标记旧快照。取消中的查询由共享请求层中断。
- 列表、详情或时间轴任一读取返回 401/403 后，统一隐藏三个区域并停止自动读取；后续 500 或拒绝前发出的迟到成功响应都不能恢复缓存。通过“重新验证并读取”成功读取当前历史和适用的时间轴后才恢复，读取期间再次撤权则继续隐藏。详情在恢复后重新打开和读取。
- Issue #181 新增 `GET /api/v1/monitor-history/status-intervals` 和状态区间时间轴。需选择开始与结束上海时间；不选国家即查询全部国家，EU 不分大小写按 UK/DE/FR/IT/ES 五国同时查询区间和覆盖证明。时间轴只使用国家、变体组 ID、ASIN ID 和时间范围，不把名称、检查类型等记录筛选错误地当作区间筛选。
- 区间来源为维护后的真实投影，只有完整覆盖时显示；覆盖不足时显示提示，仍可查检查记录。区间条按选定窗口裁剪并定位，文字同步标注正常/异常。时间轴独立分页，每页 50 条，显示区间总数；应用筛选或切换深链接时回到第一页。离散检查记录不会被前端推断成区间。

## 验证与回滚

- Web 测试覆盖 URL 去重、Legacy 目录深链接映射、多值 ASIN 与上海时间参数、`total: null`、状态与通知三态、有界结果、权限及错误状态。执行 Web test/lint/typecheck/build 和仓库基线。
- QueryClient 回归覆盖三个读取来源的权限拒绝、500 保留旧缓存但页面继续隐藏、迟到成功、恢复途中再次撤权及双源全部成功后恢复；SSR 验证区间定位、分页、空页返回与 stale 遮蔽。DB 回归比较 EU 各大小写生成的真实 SQL 和参数，并在真实 PG 下验证完整窗口分页及全国家覆盖结果。本地缺少数据库时集成用例交由 CI 执行。
- 隔离环境联调建议检查真实 PostgreSQL 数据、撤权、宽窄屏、超大结果与跳页。浏览器视觉验收若本机连接限制未解除，在 PR 中记录未执行原因。
- 回滚此 PR 可恢复 `/monitor-history` 占位页及导航状态；不涉及数据库、Legacy 或生产代理。
