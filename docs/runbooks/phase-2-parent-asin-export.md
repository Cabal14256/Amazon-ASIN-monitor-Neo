# Neo 父变体查询异步 XLSX 导出

关联 Issue #231。复用 [目录导出基础](phase-2-asin-export.md) 的任务、队列和私有产物，不增加端点或 SSE，不切换生产流量。

## 请求与实际查询

- `POST /api/v1/tasks/export` 接受 `exportType: parent-asin-query` 和 `params: { asins: string, country: string }`。ASIN 文本最多 20000 UTF-16 单元，按 Legacy 的逗号/换行拆分、去首尾空白、转大写、过滤无效项；保留有效重复项和原顺序，最多 1000 条。country 归一为 US/UK/DE/FR/IT/ES。队列只保存通过严格契约的规范数组和不可变任务身份。
- API 受理实时检查主库用户/会话与 `asin:read`。Worker 在查询前、进度、压缩和发布前重新检查当前主库用户与权限；下载仍检查当前会话、所有者和读取权限。
- Worker 惰性初始化现有 `SpApiRuntime`、`CatalogVariantChecker` 和 `CatalogParentQuery`，通过真实 LWA/签名客户端、共享 Redis 五窗口配额、缓存/延后协调和有界并发执行查询。第一轮强刷每个输入，第二轮按首次出现顺序查询不同父体标题；不是静态列表或客户端上传的结果。
- 五种导出共用用户最多 2 个 / 全局最多 100 个活动任务，以及同一 `export` Worker 最大并发 2。取消后逻辑等待结束不能提前释放尚未关闭的底层 I/O 占用；调用方 settlement 等待实际请求和数据库操作结束。

## 工作簿和恢复

- 工作表为“父变体查询结果”，11 列依次为 ASIN、国家、是否有父变体、父变体 ASIN、父体标题、产品标题、品牌、是否有变体、变体数量、查询时间、错误信息；是/否、数字和普通文本类型保持 Legacy。以等号开头的标题仍是普通文本，不作为公式。
- 查询时间在查询结束后按上海时区写为 `YYYY-MM-DD HH:mm:ss` 文本。文件名为 `ASIN父变体查询结果_YYYY-MM-DD.xlsx`。逐行 oracle 执行未修改的 Legacy 直接与异步导出函数，覆盖完整行、错误行、重复项、类型和列宽。上游错误沿用现有 Neo 父查询的脱敏错误文案，不在工作簿暴露依赖异常或凭据。
- 查询结果最多 32 MiB、1000 行；单元格最多 32767 UTF-16 单元、产物最多 256 MiB、任务最多 30 分钟。沿用实际流式压缩背压，超限失败且清理临时文件。
- 完成 ACK 丢失后重试读取原私有产物，不重新查询上游；取消已发布但未确认的任务会删除原产物。已失败/未完成任务下载返回既有 409，已完成文件撤权返回 403，损坏文件拒绝下载。

## 页面与验收边界

- `/asin-parent-query` 使用“后台查询并导出 XLSX”，按当前输入重新查询；页面支持空白/全角逗号分隔并转换为 Legacy 文本，保留重复项。输入为空、超限或查询进行中不能提交。
- 用户/会话维度的提交保护在 POST 前写入 sessionStorage。已知任务只 GET 对账；未知受理刷新后继续保护，需先核实任务中心。存储不可用不提交。换身份、会话或撤权会隔离迟到结果并丢弃旧查询数据。
- 任务中心沿用当前身份的流式保存/下载、摘要与文件子类型校验，见 [文件保存说明](phase-2-asin-export-file-save.md)。
- 真实集成需显式一次性环境 opt-in：精确 loopback 的两 PG CI 数据库、Redis /15、随机 schema/前缀、临时私有目录。编译 Worker 的真实 SP-API 传输在最终网络边界映射到受控 loopback HTTP 服务，LWA、签名、配额、目录解析和文件生成保持真实；禁止外连真实 Amazon 或使用生产凭据。未启用时的 skip 不算集成通过。
- 完整真实服务浏览器、原生文件保存和最大并发 RSS/内存上限继续由 #270 及全量资源门禁跟踪；本切片不代替生产迁移、观察或 Legacy 退役验收。

## 回滚

回滚本 Issue 提交即可撤下父查询导出接线；不涉及数据库迁移。不要删除生产数据库、队列或私有产物；仍按既有保留与清理策略处理已受理任务。Legacy 路径保持有效。
