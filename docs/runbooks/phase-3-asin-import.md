# P3：主营 ASIN 导入入口

关联 Issue #175。Neo `/asin` 为具有 `asin:write` 的用户显示 CSV/XLSX 导入；只读用户不显示上传控件。Legacy 页面和生产入口继续保留。

## 操作与结果

- 选择一个不超过 10 MiB 的 `.csv` 或 `.xlsx` 文件。浏览器通过统一 HttpClient 向 `POST /api/v1/variant-groups/import-excel` 提交 `file` 和 `useAsync=true`，由服务端再次检查格式、当前权限和容量。请求层使用与下载相同的 URL 归一化规则；`/api` 基址不会生成 `/api/api`。
- API 返回任务编号仅表示异步任务已受理。页面轮询任务详情并接收 WebSocket 失效提示，在任务中心显示逐行成功/失败、警告及受权报告下载。任务完成时刷新主营目录；失败或取消可能已有部分行提交，操作员需按任务编号核对后再决定是否重试。
- 受理结果不明时，页面保留任务编号（若服务端提供）并通过 Web Locks 持有同一浏览器的用户级锁，直至上传请求结算和本地状态写入完成。其他标签页、路由重进或浏览器重开会从本地存储恢复状态；Web Locks 或本地存储不可用则拒绝开始上传。锁不按天数自动过期，任务中心核实原任务后由操作员显式解锁；解锁也使用同一 Web Lock，期间任务状态若已变化则要求重新核实。前端不会自动重发文件，文件内容不会写入浏览器存储。
- “取消本地上传”只中断浏览器请求，服务端可能已受理任务；页面把结果视为不明，需按任务编号核实。已受理任务的取消应在任务中心执行。
- 会话或权限变化时取消正在发送的浏览器请求并清除文件选择。若服务端可能已受理，继续按不明结果处理；任务读取仍由服务端实时鉴权。

## 格式和验证

- 页面提供 CSV 模板：变体组名称、国家、站点、品牌、ASIN、ASIN 类型、可选 ASIN 名称，类型值为 1（主链）或 2（副评）。上传时按扩展名设置 API 接受的 CSV/XLSX MIME，避免浏览器或系统给出空/不一致的类型；服务端仍按内容解析和校验。列及国家、站点、合并口径由既有 Neo 导入解析器决定，详见 `docs/runbooks/phase-2-asin-import.md`。前端的扩展名与大小检查只是提前反馈，服务端校验为准。
- 回归覆盖无写权限、非法/空/过大文件、上传中撤权、500 不明受理、任务失败或取消后的部分结果核对、重进页面、任务报告和 `/api` 前缀去重。无真实账号数据时，使用隔离 API/Worker fixture；本批不切换生产数据或流量。
- 回滚 Web 提交即可移除 Neo 导入控件；已有 API、Worker、任务数据和 Legacy 路径不变。
