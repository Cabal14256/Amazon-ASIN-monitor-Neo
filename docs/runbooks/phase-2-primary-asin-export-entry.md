# Neo 主营 ASIN 目录导出入口

关联 Issue #236；复用 [ASIN 导出基础](phase-2-asin-export.md) 与 [文件保存](phase-2-asin-export-file-save.md)。本切片仅恢复主营 ASIN 页入口，不改变 Worker 布局、产物或下载协议，不切换生产流量。

- `/asin` 的“导出 ASIN”创建 `exportType: asin` 正式异步任务，只使用已应用的 `keyword` / `country` / `variantStatus`。输入框尚未提交的草稿、页码和每页数量不进入导出；不传 `layout`，沿用已验收的 Legacy 异步任务布局和 `ASIN数据_YYYY-MM-DD.xlsx` 文件名。
- 当前用户需有 `asin:read` 且不处于强制改密状态。目录加载/错误或写入中不能提交；任务受理/执行/下载仍由服务器实时授权、共享原子预算和本人所有权约束。
- 入口使用现有共享保护组件和独立 `neo:primary-asin-export:[owner,session]` sessionStorage 记录。POST 前必须持久化，网络未确认时刷新继续保留保护；已知 taskId 只 GET 对账，不自动重复 POST。确定拒绝可显式重试；没有 taskId 时须先核实任务中心。
- 页面展示原任务 ID，并链接任务中心下载或取消。换身份/会话、撤权或离页后，旧请求不更新新页面、不发布成功提示；原提交保护仍用于对账。本地中止等待不等于服务器取消。
- 任务中心沿用已验收的当前身份流式下载、文件名/字节/摘要校验及原生保存。此入口不自行下载或绕过保存授权。原变体组导出按钮、CRUD、批量、检查和导入流程保留。
- 完整挂载测试验证已应用筛选、规范 URL、未知 ACK、刷新/只读对账、确定拒绝重试、忙态/撤权及身份隔离。真实 Chrome 合成 HTTP 冒烟不替代 #270 的完整真实服务浏览器/原生文件保存门禁；skip 不计作真实集成。

回滚本 Issue 即移除该入口接线；无数据库迁移，不删除生产队列、数据或文件，不退役 Legacy。
