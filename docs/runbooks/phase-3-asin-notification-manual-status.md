# P3：Neo 主营 ASIN 通知与人工状态

关联 Issue #151。Neo `/asin` 在主营变体组详情中接通飞书通知和人工异常状态操作。竞品目录仍为只读；Legacy 页面、生产入口和生产迁移暂停状态保持现状。

## 与 Legacy 的对照

| 操作 | 权限 | 行为 |
| --- | --- | --- |
| 变体组、组内 ASIN 飞书通知 | `asin:write` | 仅切换对应记录的通知开关，不修改人工状态。 |
| 变体组人工状态 | `asin:write` | 未标记时填写原因并标记；已标记时可清除自身组标记。 |
| ASIN 自身人工标记 | `asin:write` | 未标记时填写原因并标记；自身已标记时清除自身标记。 |
| 排除父变体人工标记 | `asin:write` | 子 ASIN 继承父组人工异常时，可填写原因单独排除继承标记。 |
| 恢复父变体人工标记 | `asin:write` | 清除该子 ASIN 的排除状态，重新继承父组人工标记。 |

- 子 ASIN 同时具有自身和父组标记时，下一步先清除自身标记；之后仍可单独排除父组标记，与 Legacy 的 `SELF+GROUP` 状态规则一致。
- 操作面板显示操作前有效状态和来源。标记自身异常、标记组异常、排除父组异常都必须填写最多 500 字的原因；清除操作不需要原因。
- 写入前重读详情并比对对应通知或人工状态，检测到并发变化返回冲突提示；写入成功后刷新列表和当前详情。401/403 会遮蔽旧目录并重新验证身份。
- 400/404/409/413/429/503 显示可操作的安全提示，不回显原始服务端响应。服务端仍会校验 `asin:write` 并执行状态写入。

## 验证与回滚

- Web 服务测试覆盖四个写入 URL、请求体、契约响应和 `/api` 前缀去重；目录测试覆盖四种人工动作、`SELF+GROUP` 转移、并发变化和写权限门控。
- 已执行验证记录见关联 PR。隔离环境回归建议使用只读与可写账号检查开关/人工操作、原因必填、并发冲突及撤权后的遮蔽。浏览器视觉和真实业务数据需单独记录。
- 回滚本 PR 可恢复主营 ASIN 单项通知/人工状态之前的页面；不涉及数据库迁移、Legacy 实现或生产代理。
