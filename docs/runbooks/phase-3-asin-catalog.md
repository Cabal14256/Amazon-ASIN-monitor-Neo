# P3：ASIN 只读目录

关联 Issue #135。Neo Web 的 `/asin` 提供变体组列表和组内 ASIN 详情。只有 `asin:read` 权限用户能访问，强制改密状态仍只能进入个人中心。此页不发起任何写入、导入或导出操作；这些能力仍由后续迁移处理，Legacy 页面和生产入口不变。

## 数据与交互

- 列表读取 `GET /api/v1/variant-groups`，按服务端关键词、国家、有效异常状态和页码查询。每页可选 10/20/50/100 组；改变筛选或每页数量后回到第一页。宽屏以 TanStack Table 比例列宽展示，窄屏展示卡片；表格不对服务端当前页再做本地筛选或分页。点击组时再读取 `GET /api/v1/variant-groups/:groupId`，展示全部返回的组内 ASIN、主链/副评、有效状态、状态来源、最近检查和飞书通知状态。
- 列表组内数量优先使用完整 `children.length`。服务端 `asin_count` 在关键词筛选时可能只统计命中代码的 ASIN，与完整组内数量不同。`totalASINs` 与 `total` 的统计口径也不同，页面分别展示，不将两者相加或由当前页推算。
- 共享契约验证两个响应；请求走统一 URL 归一化，避免 `/api/api`。5000 子项的接口容量需要 120 秒和最多 32 MiB 的客户端读取上限。413、503、容量上限、空结果及重试分别显示可理解的状态；已有数据刷新失败时保留旧数据并告知用户。
- 详情使用接口提供的有效状态字段，避免从原始自动异常标记推断最终结果。时间按北京时间格式化；缺失或无效的时间不表示已经检查。

## 验证与回滚

- 自动化覆盖权限导航、接口 URL 去重、服务端筛选参数、响应契约、错误提示和状态优先级；运行 Web 测试、类型检查、Lint、构建及根级基线。
- 隔离浏览器联调建议覆盖宽屏/窄屏、只读权限、分页筛选、详情、空结果、413、503 和失效会话。联调需连接 Neo :3100 且 PostgreSQL 为鉴权权威源；Legacy 默认代理或未切换权威源时可能返回 404/503，这不代表页面已通过真实数据验收。
- 回滚本 PR 可恢复 Neo `/asin` 占位页；无数据库或生产流量回滚步骤。
