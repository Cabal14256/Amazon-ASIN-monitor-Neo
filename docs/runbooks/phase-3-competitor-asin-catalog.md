# P3：竞品 ASIN 只读目录

关联 Issue #137。Neo Web 的 `/competitor-asin` 接入竞品库变体组列表和详情。该路由要求 `asin:read`，强制改密状态仍只允许个人中心。Legacy 页面和生产入口保留；写入、检查、导入、导出及删除仍在后续迁移。

## 数据与双域差异

- 列表和详情分别读取 `GET /api/v1/competitor/variant-groups` 与 `/:groupId`，共享契约验证响应，沿用统一 `/api` URL 归一化。关键词、国家、有效异常筛选和 10/20/50/100 服务端分页与主营目录使用同一交互；宽屏比例列宽表格、窄屏卡片及详情每页 50 个子 ASIN 的展示组件复用。
- 竞品无 `site` 和人工异常字段，页面不补造这些值。竞品筛选可因父项异常命中 BROKEN，但返回的组展示状态只按子 ASIN 计算；页面使用接口 `isBroken` 原值，不能从筛选条件、`is_broken` 原字段或主营人工异常规则推断展示结果。子项 `isBroken: null` 显示未知，不当作正常。
- 竞品飞书开关的有效默认值为关闭；页面只展示服务端返回的开关。组内数量优先使用完整 `children.length`，不误用关键词口径的 `asin_count`；`total` 与 `totalASINs` 独立展示。
- 查询最多 5000 个子项、原始结果最多 32 MiB。413/503、客户端大小上限、空结果和刷新失败均有状态提示；已读取数据刷新失败时明确提示旧数据。

## 验证与回滚

- 自动化覆盖两个接口契约、URL 前缀去重、筛选参数、父组筛选与展示状态差异、无 site/source 的共享表格、路由权限、加载与错误处理；运行 Web test/lint/typecheck/build 和根级基线。
- 隔离浏览器联调建议覆盖宽屏/窄屏、权限、分页筛选、详情、大组分页、空结果、413/503、会话失效。Neo 读取需 PostgreSQL 鉴权权威源和独立竞品数据库；默认 Legacy 代理或未切换权威源可能返回 404/503，不能据此宣称真实数据验收完成。
- 回滚本 PR 可恢复 `/competitor-asin` 占位页与主营原有目录组件；没有数据库、生产流量或 Legacy 回滚步骤。
