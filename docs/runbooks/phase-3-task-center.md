# P3：Neo 任务中心

关联 Issue #139。Neo `/tasks` 使用现有任务客户端与 Query hooks 展示当前登录用户的任务列表、详情、进度和确认取消。路由继续沿用真实身份守卫，强制改密时仅开放个人中心；Legacy Tasks 页面及生产入口保留。

## 行为与边界

- 列表读取 `GET /api/v1/tasks?status=all|active&limit=100`，详情按任务 ID 读取。WebSocket 任务消息使相应 Query 失效，进度消息批量合并；列表每 15 秒兜底读取，进行中详情每 1.5 秒读取，终态停止高频轮询。断线后页面仍可手动刷新。完成/取消消息显示短暂通知。
- 只显示服务端明确返回的任务摘要、有限数量的警告、错误样本和计数，不将未知 `result` 整体序列化到页面。全部视图最多显示最近 100 条，数量不是任务总数；服务端仍按当前本人身份和任务 owner 鉴权。
- `canCancel` 必须为真且任务处于等待/执行中，并属于当前 Neo 取消 API 支持的任务类型，页面才出现确认取消。变体检查虽可能在序列化时标记 `canCancel`，当前取消 API 不支持它，因此不显示误导操作。取消成功或失败后重新读取服务端状态。
- 下载仅对已完成、带有效报告引用的主营/竞品导入任务或有效变体/批量检查结果显示。浏览器经 `TaskApi.download()` 使用同一请求层发送当前账号 Cookie 或 Legacy Bearer，读取文件有 256 MiB 上限，不使用返回的 URL 拼接或 Token 查询参数。Neo 下载端点当前不支持其他任务类型；过期或损坏文件仍由 API 返回错误。
- 本批不新增导出任务生产者、数据库或 Worker 改动，不做生产流量切换；导出/备份等尚未迁移的任务能力仍为后续阶段。

## 验证与回滚

- Web 测试覆盖任务操作资格、结果展示边界、URL 归一化、WS/轮询查询失效、路由权限；执行 Web test/lint/typecheck/build 与仓库基线。联调建议用本人及他人任务检查权限、真实 WS 推送、取消竞态、移动端布局、已完成文件与过期文件。
- 回滚本 PR 即恢复 `/tasks` 占位页与导航状态，不涉及数据库、Legacy 或生产代理。浏览器视觉验收若本机连接限制未解除，需在 PR 中记录未执行原因。
