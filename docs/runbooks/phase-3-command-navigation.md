# P3：命令面板页面导航

关联 Issue #186。工作台顶栏“跳转页面”和 Cmd/Ctrl+K 打开同一命令面板，支持当前已验证身份允许的页面导航。

## 使用与权限

- 输入页面名称或路径进行不区分大小写的筛选；方向键循环选择，Enter 打开，Tab 在输入框、选中结果与关闭按钮之间操作，Escape 关闭并返回原焦点。没有匹配结果时显示空状态，不执行导航。
- 面板直接使用 `workspaceNavigation`，遵守当前权限、强制改密和页面 `available` 标记；迁移中页面不出现在结果中。权限变化即时重新筛选；身份等待核验或失效时关闭面板，不能依靠旧结果导航。既有路由守卫继续负责目的页面授权。
- 使用原生模态 dialog 和背景 inert，打开时限制背景交互并锁定页面滚动；Tab/Shift+Tab 在面板边界循环，空结果也保持关闭按钮和输入框可达。快捷键自动重复不关闭面板。移动端侧栏或其他对话框已经打开时不抢占 Cmd/Ctrl+K；面板打开期间也不能同时打开移动导航。
- 本阶段仅提供页面跳转，不提交 ASIN 查询或写入任务；ASIN 搜索、站点切换与立即检查另行接入。

## 验证与回滚

- DOM 回归覆盖点击、两种快捷键、名称/路径搜索、方向键与 Enter、空结果、当前权限/改密/身份变化、焦点恢复、背景隔离及其他模态互斥。
- 隔离 API fixture 下的真实浏览器已验证原生 dialog top layer、点击与 Ctrl+K、中文/路径搜索、方向键与 Enter 跳页、Escape 原字段焦点恢复、Tab/Shift+Tab 循环和移动导航互斥。390×844 窄屏无横向溢出，1440×900 桌面布局通过；未使用真实账号、生产数据或外部业务 API。jsdom 仅补齐缺失的 showModal/close 方法，18 项专项回归覆盖权限、路由和键盘边界。
- 运行 Web test/lint/build、格式及 diff 检查。回滚该 Web 提交可移除命令面板，原侧栏、路由和服务端行为保持可用，无数据库变更。
