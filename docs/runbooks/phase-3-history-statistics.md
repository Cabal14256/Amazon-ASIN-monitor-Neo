# Neo 主营监控历史检查统计（#238）

`/monitor-history` 在已应用的筛选下读取真实统计接口，恢复总检查、正常、异常、监控对象数及所选国家的高低峰异常率。统计错误显示失败状态和重试操作，不以零代替失败。国家未选择时不请求高低峰接口。

## 统计范围

| 区域 | 接口 | 生效的筛选 |
| --- | --- | --- |
| 四项检查汇总 | `GET /api/v1/monitor-history/statistics` | 变体组 ID、ASIN ID、国家、检查类型、上海时间起止 |
| 高低峰异常率 | `GET /api/v1/monitor-history/statistics/peak-hours` | 国家、检查类型、上海时间起止 |

名称、ASIN 码、ASIN 类型、异常状态和分页只参与检查记录列表，不参与这两个统计。高低峰还不受组 ID / ASIN ID 限制；页面逐区域列出实际范围。数字和百分比直接来自服务器，后端百分比已为 0–100，不再乘 100 或以浏览器时区重新划分高低峰。

## 读取与恢复

- 只在当前已认证、有效账号具备 `monitor:read` 时挂载历史浏览器；用户或会话改变后销毁旧浏览器状态，以用户 / 会话为查询键的一部分。
- 统计和列表、详情、状态区间共享权限拒绝状态。任一有效请求遇到 401 / 403 后隐藏整个历史浏览器的数据，并取消及移除该历史源的缓存。
- 恢复必须重新读取当前列表、启用的状态区间和两个当前生效的统计源。任一普通失败均继续隐藏旧数据；状态区间只有既有明确“功能关闭”响应可以豁免。
- 筛选修改后点击“查询”才应用；切换范围、取消国家或离页会取消失去订阅的请求。服务传递 `AbortSignal`，使用统一 HTTP / URL 归一化、Zod 响应校验、120 秒与 32 MiB 读取边界。

## 验证与回滚

服务层回归覆盖真实 HTTP / Zod、信封、数值、取消、URL `/api` 去重和查询白名单；真实挂载页面回归覆盖应用范围、部分失败、刷新、撤权 / 恢复和会话切换。运行 `corepack pnpm --filter web test`、`lint`、`build` 与根基线。浏览器视觉验收证据和局部自动化验证须分别记录。

本项无数据库、后端口径或生产代理变更。回滚本项提交可恢复先前历史页面，Legacy 仍保留。异常时长表与 CSV 由 #233 接入；分析页、异步导出和生产切换仍按各自 Issue 推进。
