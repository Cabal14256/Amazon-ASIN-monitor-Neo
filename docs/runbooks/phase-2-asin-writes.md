# P2 ASIN 与变体组基础写入

## 入口与部署前提

本批迁移五个端点，继续保留 Legacy 路径：

| 方法 | Neo 路径                          | 行为                         |
| ---- | --------------------------------- | ---------------------------- |
| POST | `/api/v1/variant-groups`          | 创建变体组                   |
| PUT  | `/api/v1/variant-groups/:groupId` | 更新组名称、国家、站点、品牌 |
| POST | `/api/v1/asins`                   | 在指定父组下创建 ASIN        |
| PUT  | `/api/v1/asins/:asinId`           | 更新 ASIN 可编辑字段         |
| POST | `/api/v1/asins/:asinId/move`      | 移动至指定父组               |

这些端点仅在 `AUTH_DATA_AUTHORITY=postgresql` 且完成[0004 时间策略升级](./phase-2-asin-timestamp-policy.md)后写入。保留最终 Legacy 导入 →0003→0004 的顺序。策略缺失、禁用或版本不符时返回固定 503，业务事务不提交；两个既有查询端点仍可使用。

登录与 `asin:write` 权限由 HTTP 守卫检查，随后在事务内复核当前账号、密码有效期、会话与权限。带 `Origin` 的请求须匹配 `CORS_ORIGIN`；无 Origin 的受控调用沿用现有接口策略。所有响应禁止缓存，成功状态保持 200 和现有信封，写入完成日志只在事务提交后记录。

## 兼容行为与输入

- 组创建允许相同名称/国家/站点/品牌，不引入额外业务唯一约束。组编辑仅改变组本身，不重写子项国家、站点或品牌。
- ASIN 创建继承父组的有效人工状态，但不复制父组人工标记到自身字段；创建与父组更新时间触碰在同一事务。
- ASIN 编辑保留自身人工状态、排除信息、检查时间和父组 ID，也保留 Legacy 不触碰父组更新时间的行为。
- 移动保留 ASIN 国家、站点、品牌、自身人工及排除历史，仅改变父组及修改时间，并触碰源/目标组；移动到原组仍触碰时间。响应按目标组的当前人工状态计算，包括排除规则。允许组国家与子项国家不同，计数语义见[查询说明](./phase-2-asin-queries.md)。
- 类型接受数值或字符串 1/2，保存为字符串；未提供或 NULL 保存 NULL。名称为空字符串、NULL 或省略时保存 NULL；旧更新模型对省略名称可能传入 MySQL 不支持的 undefined，此处按现有可选契约明确清空。
- 请求对象最多 20 键，未知写字段拒绝；必填文本拒绝全空白和控制字符，接受的大小写与空白保持原样。按数据库字符语义计 Unicode 码点：国家 10、站点/品牌 100、组名 255、ASIN20、名称 500、ID 50；补充平面字符不会被错误减半。当前不模拟 MySQL 的全部重音/Unicode 排序规则，真实数据对拍仍须验收。

## 事务、并发和错误

数据库事务使用 READ COMMITTED、共享全局 RBAC advisory lock 和当前账号/会话共享行锁。管理侧权限修改持排他锁，业务写等待后必须重新读取权限。策略准备函数持有两张业务表的兼容表锁，阻止触发器 DDL 在探针通过后插入事务，并开启仅本事务有效的显式时间模式。

业务行锁先锁父组、再锁 ASIN；多个组按数据库 ID 顺序锁定。更新/移动先读取候选源组，按序锁源组/目标组，再锁 ASIN 并复核所属关系。如另一个移动已经改变父组，返回 409 要求刷新，不在持锁途中改锁另一个未排序的源组。后续删除、人工标记和监控处理器须遵循同一顺序。

ASIN/国家大小写重复由数据库唯一约束裁决，包括不同父组上的并发创建。只把两个已知 ASIN 唯一约束的 23505 映射为 409；其他数据库异常返回固定 500，不输出 SQL、参数或驱动对象。父组不存在/ASIN 不存在返回 404。缺少权限返回 403，非法输入 400，事务容量耗尽 429。API 最多 8 个本域写请求，仓储最多 16 个在途事务，沿用 2 秒事务总截止与 1.5 秒 SQL 截止。

响应在事务内构建，提交完成后才返回。组编辑需要返回完整子项，超过 5000 项时返回 413 并回滚组修改；插入、父组触碰、移动或响应构建中任何失败均回滚整个业务事务。单个 ASIN 响应直接读取当前 ASIN 与父组，不因父组子项总数超过 5000 而截断或扩大读取。

## 验证与回滚

本地参数测试用实际 Legacy 控制器对拍，响应测试用实际 Legacy ASIN 模型对拍，HTTP 测试覆盖五路由、当前授权、Origin、固定错误、容量及提交后成功。真实 PG/Redis 夹具显式安装外键、两个命名唯一约束/索引和 0004 触发器，覆盖重复创建、状态继承、父组时间、反向/竞争移动、撤权等待、超界响应与故障回滚；不能用不含触发器的 LIKE 表代替实际写验收。

发布前运行根 17 项基线及 API 测试类型检查，并要求最新 CI/Integration 通过。正常回退本批 API 代码即可恢复使用 Legacy 入口；已经提交的 Neo 数据不能用旧快照覆盖。若需撤销 0004，必须先停止依赖它的写路径，再按时间策略运行说明回滚 DDL。当前未执行生产写入切换；删除、批量创建/导入、通知、人工标记、检查与 Worker 仍由后续批次迁移。
