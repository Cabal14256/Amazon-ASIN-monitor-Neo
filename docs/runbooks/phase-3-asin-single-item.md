# P3：Neo 主营 ASIN 单项管理

关联 Issue #149。Neo `/asin` 在共享目录中接通主营变体组和组内 ASIN 的单项写入，竞品目录继续只读。Legacy 页面、生产入口及生产迁移暂停状态保持现状。

## 与 Legacy 的对照

| 操作 | Neo 入口 | 规则 |
| --- | --- | --- |
| 新建、编辑变体组 | 列表上方、组详情 | 名称、国家、站点（店铺代号）、品牌必填；编辑前及提交前重读目标。 |
| 添加、编辑组内 ASIN | 组详情 | 新建仅接受一个 10 位字母数字 ASIN，自动大写；编辑时 ASIN 编码不可改，名称、国家、站点、品牌、主链/副评类型可改。 |
| 移动 ASIN | 组内 ASIN 操作 | 按名称/编号/ASIN 搜索目标组，排除当前组，并在提交前确认目标。 |
| 删除组或 ASIN | 组详情、组内 ASIN 操作 | 明确确认；删除变体组会连带删除其组内 ASIN。 |

- `asin:write` 控制创建、编辑、移动；`asin:delete` 控制删除，服务器继续做最终授权与业务约束检查。
- 写入期间禁用重复提交。成功后重新读取目录与详情；若写入或操作前重读收到 401/403，立即遮住旧目录数据、清除用户查询并重新验证身份。400/404/409/429/503 提供不暴露原始服务端内容的提示。
- 编辑表单打开前读取最新详情；提交前再次比对原始字段，若其他管理员已修改同一记录，要求关闭表单后重开。上海时间和状态展示继续沿用共享只读目录逻辑。
- 共享表单与确认组件通过目录配置注入写入服务，为后续竞品目录迁移提供复用基础；本次不启用竞品写入口。

## 验证与回滚

- Web 服务测试覆盖七个单项写入、契约响应与 `/api` 前缀去重；目录测试覆盖权限控制、编辑并发冲突、单项 ASIN 输入和错误信息。执行完整仓库基线、Web 类型/Lint/构建和 CI 隔离集成检查。
- 隔离环境回归建议分别使用只读、仅写入、仅删除、同时具备写入和删除权限的账号，检查组与 ASIN 的单项操作、目标搜索、并发编辑冲突、撤权后的遮蔽，以及窄屏布局。真实数据与浏览器视觉验收需另行记录结果。
- 回滚本 PR 可恢复主营只读目录；不涉及数据库迁移、Legacy 实现或生产代理。批量操作、通知/人工标记、导入、检查和导出属于后续独立范围。
