# Neo 主营监控历史异步 XLSX

关联 #174，供 #157 分析页接线；#233 继续负责完整历史筛选、状态变化布局和真正异常时长 CSV。复用 [异步导出基础](phase-2-asin-export.md)，不增加 SSE、不切换生产流量。

## 请求与授权

- `POST /api/v1/tasks/export` 支持 `exportType: monitor-history`，params 仅支持 country/startTime/endTime，可省略。时间为有效上海日期或 `YYYY-MM-DD HH:mm:ss[.SSS]`，拒绝带时区的瞬时值、非法日期和额外字段；尚不接受 records/statusChanges 切换或目录/ASIN/名称等筛选，调用方不得假装这些字段已支持。
- 导出端点按已验证的类型在控制器服务事务内授权，与冻结端点清单一致。历史创建/执行/下载要求当前 `monitor:read`，其他五种导出仍要求 `asin:read`。仅有 ASIN 权限不能创建/下载历史；仅有监控读取权限不需额外 ASIN 权限。会话、改密、账户和本人所有权仍实时检查。
- 六种导出共享用户最多 2 / 全局最多 100 活动任务，以及同一个 export Worker 最大并发 2。任务创建时间、所有者与子类型用于对账和状态 CAS，不能通过新导出类型绕开预算。

## 快照与工作簿

- 主库业务读取使用独立最大 2 连接池和同一个 `REPEATABLE READ READ ONLY` 快照；短授权事务使用原授权池，避免两个长导出占满连接后无法重查权限。SQL 按 `(check_time DESC,id DESC)` 原生 keyset，每页最多 500 行，不走 OFFSET/COUNT 列表 API。
- 游标保留数据库微秒和完整正 bigint ID，不转换成 JavaScript number；时间单元格按 Legacy 以秒级上海墙钟文本显示。缺省 endTime 在任务执行时冻结一次，所有页使用同一个值。
- SQL 在完整结果 JSON 序列化前做 16 MiB 页预算测量；工作簿最多 100000 数据行、每单元格最多 32767 UTF-16 单元、私有产物最多 256 MiB、任务最多 30 分钟。实际流式压缩等待背压，超限失败且清理，不截断记录。
- 工作表“监控历史”，13 列依次为检查时间、检查类型、变体组名称、ASIN、ASIN 名称、ASIN 类型、国家、检查结果、状态来源、人工操作、人工原因、操作人、检查详情。保留列宽及灰色加粗表头；文件名 `监控历史_YYYY-MM-DD.xlsx`。
- 读取保留快照字段优先、关联目录回退规则，类型名与手动操作文本沿用 Legacy。Legacy DDL 的 check_result 是 TEXT，mysql2 不预解码；Neo JSONB::text 与原 formatter/人工信息提取均只解析一次，保留 JSON null、标量和嵌套字符串，嵌套字符串不能变成人工元数据。JSONB 对象键顺序不属于值等价；真实双库 oracle 仅在检查详情列按完整 JSON 值规范化，其他列/顺序/类型/宽度逐项比较，纯函数 oracle 仍比较完整文本与样式。
- 结构化历史人工元数据若看起来像 Excel formula/hyperlink 定义，会序列化为普通文本，避免执行外部定义；普通字符串以等号开头也保持字符串。这个安全收紧与 Legacy 直接传对象的行为不同，单独测试，不伪装为原样公式执行。

## 恢复与下载

- 与父变体导出复用同一个已验收产物生命周期：私有临时文件、完整性、原子发布、ACK 不确定对账、取消/失败/拒绝证明恢复与清理。已发布文件重试复用，不重新读取历史；取消优先于并发完成和迟到 SQL 回调。
- 任务中心按 `monitor:read` 独立显示下载并纳入保存 scope；ASIN 权限仍在但监控权限撤销时也取消等待，迟到数据不得保存。继续使用 [现有文件保存](phase-2-asin-export-file-save.md) 的当前身份、字节、摘要、超时和物理清理预算。
- 已失败/未完成任务下载仍为 409，已完成文件撤权为 403，非本人任务拒绝，损坏/过期文件拒绝。页面创建入口由后续 #157 接入，本切片不代替分析性能门禁。

## 验证与回滚

- 单元测试执行未修改的 Legacy 直接/任务导出函数，对照完整 13 列、JSON 语义、空值、类型、宽度与表头样式；覆盖多页、ACK 丢失、取消发布竞态、撤权与页/cell/字节预算，保留父查询和实际背压回归。
- 真实隔离 CI 显式 opt-in，精确 loopback 的 CI 两 PG 数据库、MySQL 和 Redis /15，使用随机 schema/MySQL database/Redis 前缀及临时私有目录。实际 MySQL 原模型/导出与 TimescaleDB→ 编译 Worker→HTTP 下载 oracle，覆盖超过 500 行、完整 bigint、微秒、并发删除、授权可写、取消 SQL 锁等待、撤权/越权/损坏。
- 本机未启用真实服务时 skip 不算集成通过。完整真实服务浏览器、原生保存、最大并发 RSS 和端点/任务总报告仍由 #270、#190 及相应独立门禁跟踪。
- 回滚本 Issue 撤下监控历史类型；不涉及数据库迁移，不删除生产数据或队列，不执行生产部署、切流或 Legacy 退役。
