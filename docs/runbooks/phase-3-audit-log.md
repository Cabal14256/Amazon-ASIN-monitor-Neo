# P3：Neo 操作审计页面

关联 Issue #145。Neo `/audit-log` 通过受 `audit:read` 保护的 `GET /api/v1/audit-logs` 与 `GET /api/v1/audit-logs/:id` 提供只读列表及详情。Legacy 页面与生产入口继续保留。

## 行为与边界

- 服务器执行用户 ID、用户名、操作类型、资源类型、资源 ID 和时间筛选。用户名为包含匹配，其余文本字段依 API 规则等值匹配。时间表单按上海墙钟发送，由服务器转换为绝对时刻；结束时间不能早于开始时间。
- 列表按服务器的创建时间降序、ID 降序排列，展示精确总数。默认每页 10 条，可选 20/50/100；切换筛选、页码或每页数量时收起旧详情。
- 宽屏表格与窄屏卡片展示用户、操作、资源、时间、路径/方法和响应状态；详情额外展示资源标识、IP、User-Agent 和错误信息。`requestData` 不在页面展开，避免展示任意请求内容。
- 列表/详情按共享契约、当前会话与权限读取，API 响应标记 `Cache-Control: no-store`；列表或详情收到 401/403 后立即遮住旧列表，后续网络/服务错误也不会重新显示旧快照，只有拒绝发生后启动的列表读取成功才恢复。详情收到 404 后保留已删除状态，直至该详情重新读取成功或用户关闭详情。400/401/403/404/503/504、空结果、响应过大及刷新失败均提供反馈。

## 验证与回滚

- Web 测试覆盖筛选/上海时间请求、URL 前缀去重、分页/详情响应校验、列表/详情撤权与删除后的旧快照遮蔽、错误提示与路由/导航权限；API 测试覆盖审计读取的 `no-store`。执行 Web 与 API test/lint/typecheck/build 和仓库完整基线。
- 隔离环境联调建议检查真实 PostgreSQL 审计数据、撤权和会话失效、宽窄屏与长字段。若本机浏览器连接限制仍在，在 PR 中记录视觉验收未执行原因。
- 回滚此 PR 可恢复 `/audit-log` 占位页及导航状态，并移除只读 API 的 `no-store` 响应头；不涉及数据库、审计写入、Legacy 或生产代理。
